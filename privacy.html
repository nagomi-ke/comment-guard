プライバシーポリシー / Privacy Policy

Nagomi-ke Comment Guard は、チャンネル運営者本人の Google アカウントで YouTube Data API を使い、運営者自身のチャンネルに投稿されたコメントを読み取り、不適切なものを削除します。

  • 取得するデータ: 運営者のチャンネルに投稿された公開コメント（本文・投稿者名・投稿日時）
  • 利用目的: コメントの管理（不適切なコメントの削除）のみ
  • 保存: 運営者の手元のコンピュータに処理記録として保存し、第三者に提供・販売しません
  • 第三者のアカウントへのアクセスや、運営者以外のユーザーデータの収集は行いません

This tool uses the YouTube Data API with the channel owner's own Google account to read comments posted on the owner's channel and remove inappropriate ones. Data is used only for comment moderation, stored locally on the owner's computer, and never shared or sold. YouTube API Services are used in accordance with the YouTube Terms of Service and the Google Privacy Policy.
